| Boundary | Description |
|----------|-------------|
| Offline client to batch API | Operation IDs, payload fingerprints, base versions, and task changes are untrusted. |
| Batch API to PostgreSQL | Idempotency receipt and task effect must be atomic across API instances. |
| Administrator to conflict resolution | Resolution is privileged and must preserve both original versions. |
