<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Client to summary API | Farm ID, week anchor, cycle ID, sharing target, and summary ID are untrusted request inputs. |
| Structured farm data to projection | Farm/time/cycle and correction boundaries must exclude cross-farm, unconfirmed, and superseded records. |
| Worker to prose provider | The model receives a bounded projection and returns untrusted narrative/source references. |
| Advisor to summary/source routes | A previously valid grant can expire, be revoked, or lose compatible scope between requests. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-05 | S | Summary request, share, and source reads | high | mitigate | Re-read active farm membership and the exact advisor grant/scope from PostgreSQL on each operation. |
| T-04-06 | T | Deterministic totals and narrative output | high | mitigate | Calculate totals only from structured rows; validate every model section/source ID against the immutable projection and preserve original unit/currency groups. |
| T-04-07 | I | Advisor summary and source response | high | mitigate | Return only scope-compatible sections/source rows, filter pending-task details, and test revocation and scope mutation between requests. |
| T-04-08 | D | Weekly source projection and prose job | medium | mitigate | Bound date window, cycle query, provider input/output sizes and job retries; report incomplete/missing data instead of silently summarizing a truncated set. |
| T-04-SC | T | NuGet package installation | high | mitigate | This plan adds no package; if a dependency is proposed, require package-legitimacy audit and a blocking human checkpoint for `[ASSUMED]` or `[SUS]` packages before install. |
