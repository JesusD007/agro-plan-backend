<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Client to symptom-report API | Farm IDs, photo metadata, report IDs, and review actions are untrusted. |
| API/Worker to private photo storage | Photo references and temporary access tokens cross the storage boundary. |
| Worker to observation provider | Images and crop/parcel context are sensitive; model output is untrusted and observation-only. |
| Reviewer identity to agronomist authority | Verification and farm assignment must be current and independently persisted. |
| Review transition to media cleanup | Close/reject events must delete only this report's private photos without deleting its audit record. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-09 | E | Agronomist review endpoint | high | mitigate | Require trusted current verification plus explicit non-revoked farm authorization on every review; recheck report membership/consent before provider calls and publication. |
| T-04-10 | I | Symptom photos and report reads | high | mitigate | Use private farm-scoped media keys, short-lived access, current report authorization, and integration tests for cross-farm access. |

| T-04-12 | R | Agronomist decisions and media deletion | medium | mitigate | Persist reviewer identity/time and append-only decisions; store per-object deletion state and retries while retaining the report. |
