# Plan 01-12: Provider-Neutral AI Boundary and Setup E2E Gap Closure

## Objective

Close review findings discovered after the initial Phase 1 verification: generalize AI provenance, enforce common validation for every provider adapter, cover unsafe draft responses with xUnit v3, and exercise account-to-farm setup over HTTP.

## Tasks

1. Add provider identity to the shared AI draft contract while keeping Gemini as the registered adapter.
2. Validate each AI draft in worker orchestration after the adapter call and before serialization/persistence. Reject missing or oversized summaries, numeric claims, unknown sources, invalid missing-input IDs, and incomplete provenance.
3. Add unit coverage for valid drafts, rejected provider-neutral drafts, and malformed raw Gemini JSON.
4. Add a PostgreSQL-backed HTTP test for registration, farm creation, parcel creation, and readback, including role-denial checks.
5. Run the complete solution suite, record actual test counts, and rerun phase verification.
