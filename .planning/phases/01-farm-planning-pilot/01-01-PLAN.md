## Trust Boundaries

| Boundary | Description |
|---|---|
| Client to API | Untrusted credentials, IDs, and request bodies cross HTTPS boundary. |
| API to PostgreSQL | Identity, membership, farm rows, refresh state, and recovery state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-01 | Spoofing | Identity endpoints | high | mitigate | Identity password hashing, bounded login throttling, short-lived signed tokens and hashed rotating refresh tokens. |
| T-01-02 | Elevation of privilege | FarmMembershipAuthorizationHandler | high | mitigate | Query active membership from PostgreSQL for every scoped API operation; tenant-scoped resource query and FK constraints. |
| T-01-03 | Information disclosure | RecoveryService | high | mitigate | Generic public responses, expiring one-time codes, attempt limits, support audit and no password exposure. |
| T-01-04 | Tampering | Farm/parcel persistence | medium | mitigate | Validate ownership and persist farm/membership changes transactionally with audit records. |
| T-01-SC | Tampering | NuGet package installs | high | mitigate | Verify official docs, NuGet publisher/source/release history and major-version compatibility before every pin; block unresolved suspicious packages. |
</threat_model>
